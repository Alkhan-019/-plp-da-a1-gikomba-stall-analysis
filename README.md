## Project Overview

This project analyses 14 days of sales and inventory data from Wanjiku's market stall at Gikomba Market.

The analysis uses Python to evaluate sales performance, identify purchasing patterns, classify daily sales and assess inventory levels.

## Project Objectives

- Calculate basic sales statistics.
- Compare weekly sales performance.
- Classify daily sales performance.
- Compare weekday and weekend sales.
- Analyse inventory and stock levels.
- Prepare a stall performance report.
- Provide practical business recommendations.

## Tools and Technologies

- Python
- Jupyter Notebook
- Data analysis
- Git and GitHub

## Key Findings

| Metric | Result |
|---|---:|
| Total sales | KES 46,450 |
| Week 1 sales | KES 22,050 |
| Week 2 sales | KES 24,400 |
| Weekly sales growth | 10.66% |
| Average weekday sales | KES 2,975 |
| Average weekend sales | KES 4,900 |

## Business Recommendations

1. Increase weekend stock availability.
2. Prioritise restocking fast-moving products.
3. Monitor daily sales performance.
4. Improve inventory management.
5. Use sales trends to guide purchasing decisions.

## Project File
